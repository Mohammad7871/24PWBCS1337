Step-by-Step Guide

how to deploy on GitHub Pages
1

Create a GitHub Repository

Go to github.com → Click New → Name it Lab3 → Set it to Public → Click Create repository.

2

Initialise Git and Push Files

Open VS Code terminal inside your project folder and run these commands:

# Initialise git inside the project folder
git init
git add .
git commit -m "Initial commit – Lab 03 & 04"
# Connect to your GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/Lab3.git
git branch -M main
git push -u origin main
3

Enable GitHub Pages

On your repository page go to: Settings → Pages → Under Source select main branch and / (root) → Click Save.

4

Your Site is Live!

After 1–2 minutes your site will be published. The URL will follow this pattern:

🌐
Your GitHub Pages URL: https://YOUR_USERNAME.github.io/Lab3/
5

Update Your Site

Whenever you make changes to your files, push them to GitHub and the site updates automatically:

git add .
git commit -m "Updated styling"
git push
