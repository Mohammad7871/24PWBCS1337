Exercise 1 – CSS Implementation Methods

Demonstrating Inline, Internal, and External CSS

Method 1 – Inline CSS

style attribute

This heading is styled using Inline CSS (style="color: red;")

Inline CSS is written directly inside the HTML tag using the style attribute. It has the highest specificity but is hard to maintain.

Method 2 – Internal CSS

<style> tag in <head>

This paragraph is styled using Internal CSS. The style is written inside a <style> tag in the <head> section.

Internal CSS applies to the whole page but only that one file. Good for single-page styling.

Method 3 – External CSS

<link> to style1.css

This paragraph is styled using External CSS. The style comes from the file style1.css which is linked in the <head> using a <link> tag.

External CSS is the best practice for real websites. One CSS file can style many HTML pages.
