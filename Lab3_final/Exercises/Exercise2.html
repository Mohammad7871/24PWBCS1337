Exercise 2 – Basic Selectors

Element, Class, ID and Universal Selectors

Element Selector – h1 { color: blue; }

element selector

This heading is blue because of the h1 element selector

All <h1> tags on the page will automatically get this colour.

Element Selector – p { color: green; }

element selector

This paragraph is green because of the p element selector.

Every paragraph on the page gets the same style.

Class Selector – .highlight { background-color: yellow; }

class selector

This paragraph has class="highlight" so it gets a yellow background.

This paragraph has no class, so no yellow background.

Class selectors start with a dot (.) and can be reused on many elements.

ID Selector – #special { color: red; }

id selector

This paragraph has id="special" – red colour and left border.

ID selectors start with # and should be unique on the page.

Universal Selector – * { font-family: Arial; }

universal selector

The universal selector (*) at the top of this page applies font-family: Arial to every single element. That is why all text on this page uses the Arial font.
