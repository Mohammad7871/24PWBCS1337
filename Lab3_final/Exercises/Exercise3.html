Exercise 3 – Attribute Selectors

Selecting elements by their HTML attributes

input[type] – Any input that has a type attribute

presence selector

Both inputs share the gray border because both have a type attribute.

input[type="text"] – Only the text input

exact value selector

a[href*="google"] – Link whose href contains "google"

contains selector [*=] Google ← red colour (href contains "google")

Facebook ← normal colour

a[href^="https"] – Links starting with https

starts-with selector [^=] Google (bold)

Facebook (bold)

Both are bold because both start with "https".

a[href$=".com"] – Links ending with .com

ends-with selector [$=] Google (underline)

Facebook (underline)

Both are underlined because both end with ".com".
